# Marp presentations

A minimal Marp CLI presentation project with a custom hockey theme.

## Requirements

Node.js and npm.

## Setup

```sh
npm install
npm run serve
```

Open http://localhost:8000 in your browser.

## Export

```sh
npm run html
npm run pdf
npm run pptx
```

Edit Markdown files in `decks/` and CSS themes in `themes/`.
